# Етап 01. База сайту

Дата: 19.08.2026

Це перша робоча версія сайту Dandelion_ua. Її можна відкрити локально і вже клікати по сторінках.

---

## 1. Що додано

- Головна сторінка
- Список модів у вигляді карток
- Окрема сторінка мода (опис, скріншоти, вимоги, кнопка завантаження)
- Базова навігація: Головна / Моди
- Перемикач мови EN / UA (англійська стоїть за замовчуванням)
- Адаптивність для телефона і комп'ютера
- Три демо-моди, щоб сітка і сторінки не були порожніми

---

## 2. Як це зроблено

Стек навмисно простий: чистий HTML + CSS + JavaScript. Без фреймворків.

### Файли

```
dandelionua/
  index.html              головна
  mods.html               список модів
  mod.html                один мод (?id=...)
  css/style.css           усі стилі
  js/mods-data.js         дані модів (єдине місце)
  js/i18n.js              переклади інтерфейсу і мова
  js/main.js              картки, пошук, галерея, шапка
  assets/logo.svg
  assets/favicon.svg
  assets/placeholder-*.svg
  Інструкція.txt
  STAGE_01_BASE.md
```

### Дизайн

- Темний фон, сітка 16px, товсті рамки, тінь «як у блоку».
- Акценти: жовтий `#f4c430`, синій `#4da3ff`.
- Додаткові: темно-сірий і зелений `#6bbf4e`.
- Шрифт: **DotGothic16** з Google Fonts для всього тексту.
- Запасний шрифт: **Pixelify Sans**. DotGothic16 погано тягне кирилицю, тому українські літери беруться з Pixelify Sans. Це тимчасове рішення, поки не підберемо один піксельний шрифт з повною підтримкою EN + UA.

### Мова

- Ключ у `localStorage`: `dandelion-lang` (`en` або `ua`).
- Тексти інтерфейсу лежать у `js/i18n.js`.
- Тексти модів лежать у `js/mods-data.js` у парі `en` / `ua`.
- На HTML-елементах стоїть `data-i18n="ключ"`.
- Мова застосовується одразу після завантаження і після кліку EN / UA.

### Моди

Один запис у `window.Dandelion.mods` дає картку, пошук і сторінку мода.

Важливі поля:

- `id` — для посилання `mod.html?id=...`
- `featured` — чи показувати на головній
- `title`, `short`, `description` — об'єкти `{ en, ua }`
- `version`, `mcVersion`, `loader`
- `downloadUrl` — порожній рядок = кнопка «Незабаром»
- `requirements` — списки для обох мов
- `screenshots` — шляхи до картинок
- `status: "placeholder"` — жовтий бейдж «Демо» і синє попередження на сторінці мода

Зараз у базі три вигадані моди:

1. `wild-dandelions`
2. `pocket-workshop`
3. `skyroot-trails`

Це не справжні моди друга. Вони лише тримають макет.

### Сторінки

- `index.html` — герой, обрані моди, блок про автора.
- `mods.html` — усі картки + пошук по назві, опису, лоадеру і версії.
- `mod.html` — збирається з даних. Є галерея (клік по мініатюрі міняє велике фото) і бічна колонка з вимогами. Якщо `id` невідомий, показується «мод не знайдено».

Сайт можна відкрити просто файлом (`index.html`) або через локальний сервер. Запити на сервер не потрібні.

---

## 3. Що варто знати перед наступними змінами

1. Новий мод додаю тільки в `js/mods-data.js`. HTML чіпати не треба.
2. Новий рядок інтерфейсу додаю в обидві мови в `js/i18n.js`, потім ставлю `data-i18n` у HTML.
3. Справжні скріншоти кладу в `assets/` і прописую шлях у записі мода.
4. Коли з'явиться файл мода — вписую URL у `downloadUrl` і прибираю `status: "placeholder"`.
5. Кольори і шрифт міняю в `:root` у `css/style.css`.
6. Шапка зараз скопійована в три HTML-файли. Якщо міняю навігацію — міняю в усіх трьох.
7. Перед будь-якою зміною вимог спочатку оновлюю `Інструкція.txt`.

---

## 4. Обмеження цього етапу

- Немає справжніх модів, скріншотів і файлів для завантаження.
- Немає бекенду, акаунтів, коментарів і статистики завантажень.
- Пошук працює тільки на сторінці списку і тільки в браузері.
- Кирилиця йде через запасний шрифт, не через DotGothic16.
- На дуже вузькому екрані меню ховається за кнопкою ☰.

Цього досить, щоб далі додавати функції по одній і не ламати вже зібрану базу.
