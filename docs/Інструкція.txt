# Інструкція проєкту: Сайт модів Dandelion_ua

Я (власник проєкту) створюю сайт для модів Minecraft, які робить мій друг під ніком **Dandelion_ua**.

Розробка ведеться **поступово**. Спочатку тримаємо мінімальну базу, потім додаємо лише те, що я прошу.

---

## 1. Мета проєкту

Створити сайт, на якому можна:
- Переглядати список модів Dandelion_ua
- Читати описи, дивитися скріншоти
- Завантажувати моди

Це довгострокова мета. Зараз сайт ще не має цих розділів.

---

## 2. Правила роботи зі мною (Grok)

- Інструкція і файли етапів лежать у папці `docs/`. У корені сайту їх немає.
- Після **кожного завершеного етапу** ти створюєш окремий текстовий файл (наприклад `STAGE_01_BASE.md`, `STAGE_02_...md` тощо) у папці `docs/`.
- У цьому файлі детально описуєш:
  - Що саме було додано
  - Як саме це зроблено (структура файлів, ключові рішення, які технології/підходи використані)
  - Де що лежить
  - Які є важливі моменти для майбутніх змін
- Якщо виникає проблема, помилка або потреба щось змінити — ти спочатку дивишся ці документи, щоб швидко зрозуміти поточний стан і не ламати те, що вже працює.
- Усі відповіді та документацію ти пишеш **від мого обличчя** (від першої особи, як інструкції від мене).
- Кожен етап закінчується робочою версією, яку можна подивитися.

### Контент — головне правило

- **Нічого не додавати від себе.** Не вигадувати тексти, назви, описи, фото, скріншоти, демо-моди, факти про автора.
- На сайті може бути лише те, що я явно дав.
- Я даю матеріал **українською**. Ти перекладаєш його і додаєш **англійською**. Обидві мови мають бути на сайті.
- Якщо чогось немає — лишаємо порожнім. Не заповнюємо «поки що» своїм текстом.

### Дизайн

- Оформлення ставлю **тільки те, що я назвав** (кольори, смужки, картинки, розташування). Нічого не вигадувати зверху.
- Піксельний шрифт: **Tiny5** з Google Fonts (є англійська і українська).
- Виділення тексту: фон `#eebd3b`, літери майже білі з легким блакитним (`#eaf4fc`).
- Майбутній темний Minecraft-вайб окремо не впроваджуємо, якщо я сам цього не попросив.

## 3. Мови сайту

- Основна мова за замовчуванням: **англійська**
- Є перемикач на **українську**
- Інтерфейс і контент мають підтримувати обидві мови

---

## 4. Технічний стек

- Чистий HTML + CSS + JavaScript (без важких фреймворків)
- Усе зберігається в папці проєкту
- Тестової сторінки з лайками немає. `docs/supabase.sql` і `js/config.js` лишились на потім, якщо знову знадобляться спільні цифри.
- `server.py` лишився тільки для локальної перевірки. GitHub Pages його не запускає.

## 6. Структура документації етапів

Кожен файл етапу має містити:
1. Назву етапу і дату
2. Список того, що було додано / змінено
3. Детальний опис реалізації (файли, ключові класи, підходи)
4. Що варто знати для наступних змін
5. Відомі обмеження або тимчасові рішення (якщо є)
