# Етап 03. Папка документації і іконка вкладки

Дата: 19.08.2026

---

## 1. Що змінено

- Інструкція і всі файли стадій перенесені в окрему папку `docs/`
- Іконку вкладки браузера замінено на `assets/dandelion_ua_site_logo.png`
- Кульбаба на самій сторінці не чіпалась
- Старий `assets/favicon.svg` прибрано: вкладка більше його не використовує

---

## 2. Як це зроблено

### Документація

Тепер так:

```
dandelionua/
  docs/
    Інструкція.txt
    STAGE_01_BASE.md
    STAGE_02_SIMPLE.md
    STAGE_03_DOCS_AND_FAVICON.md
  index.html
  css/
  js/
  assets/
```

У `Інструкція.txt` записано, що нові етапи треба класти саме в `docs/`.

### Іконка вкладки

У `index.html` замість:

```html
<link rel="icon" href="assets/favicon.svg" type="image/svg+xml">
```

стоїть:

```html
<link rel="icon" href="assets/dandelion_ua_site_logo.png" type="image/png">
```

Файл PNG я сам поклав у `assets/`. На сторінці як і раніше показується `assets/logo.svg`.

---

## 3. Що варто знати перед наступними змінами

1. Нові `STAGE_*.md` і правки інструкції — тільки в `docs/`.
2. Іконка вкладки і картинка на сторінці — це різні файли.
3. Текст на сторінці в цьому етапі не мінявся.

---

## 4. Обмеження

- Деякі браузери кешують іконку вкладки. Якщо стара кульбаба ще висить — треба оновити сторінку з очищенням кешу.
