# Етап 46. Скролбари по місцях, кнопки вище, тип «пост»

Дата: 20.08.2026

---

## 1. Що змінено

- Кнопки керування текстом підняті майже під комірку, з маленьким відступом.
- Блакитний скролбар без фону — у гуішці створення поста (замість браузерного), не на головній.
- На головній: зелений бігунок, фон смуги `#375942`. Зелений прямокутник на футері прибрано — футер нічого не перекриває.
- У формі тип «публікація» перейменовано на «пост» / «post». Розділ сайту лишився «Публікації».
