# Етап 70. Літера-кнопка у футері

Дата: 21.08.2026

---

## 1. Що змінено

- Окрема квітка після тексту прибрана.
- Кнопка — літера **D** / **Д** у «Dandelion» / «Данделіона». Виглядає як звичайний текст: курсор не змінюється, звуку кліку немає.
- Клік усе одно гортає текстури (літера стає квіткою 1em) і рахує пасхалку (18 × ≤400 мс).

---

## 2. Як саме

HTML: `footer_before` + `.footer-flower` + `footer_after`. CSS `cursor: var(--site-cursor)`. Кеш `?v=73`.

---

## 3. Що варто знати

Якщо змінювати речення футера — тримати розбиття так, щоб літера лишалась першою в «Dandelion» / «Данделіона».
