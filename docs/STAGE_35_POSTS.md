# Етап 35. Публікації лише для адміністратора

Дата: 20.08.2026

---

## 1. Що змінено

- На головній з’являються пости: назва, опис, фото.
- Кнопка «Створити публікацію» видна тільки адміністратору.
- Форма: назва EN/UA, опис EN/UA, до 4 фото (jpg/png/webp/gif).
- Адмін — це не схована кнопка, а мітка `is_admin` у таблиці `accounts`.

---

## 2. Як саме

Файл `docs/posts.sql`. RPC `list_posts` (усі читають) і `create_post` (пише лише `is_admin`).

Фото йдуть у таблицю `post_photos` як base64. Сховище Storage не ставив: наш вхід не через Google/JWT.

JS: `js/posts.js`. Кнопка `[data-admin-only]` ховається, поки `account_me` не скаже `is_admin: true`.

---

## 3. Що варто знати

1. У SQL Editor виконай `docs/posts.sql`.
2. Потім свій нік зроби адміном (підстав свій нік):

```
update accounts set is_admin = true where lower(nick) = 'твій_нік';
```

3. Вийди і зайди знову, щоб підтягнулась мітка.
4. Фото краще до ~500 КБ.

---

## 4. Обмеження

Великі фото база не прийме. Редагувати / видаляти пости ще не можна.
