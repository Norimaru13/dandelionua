# Етап 45. Скролбари, фільтри, панель під текстом

Дата: 20.08.2026

---

## 1. Що змінено

- На головній скролбар знову зелений (`#28402f`) зі смужкою-фоном `#7d8bb8`. На футер не заходить: там 24px `#578c67`.
- У комірці тексту публікації — блакитний скролбар `#6371af` без фону.
- Кнопки керування текстом під коміркою, правіше RGB-смужок.
- Поле коду кольору приблизно вдвічі ширше.
- Фільтри: тип проєкту → платформи (додано Vanilla) → версії → стан → статус.

---

## 2. Як саме

Окремий `.scroll-end-cap` лежить поверх рейки на висоті футера, тому блакитна смужка більше не наїжджає.
