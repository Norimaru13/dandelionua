## 1. Що змінено

- На головній є кнопка (сердечко + око, без вигаданого напису), веде на `post.html`
- `post.html` порожня: тільки сердечко, око і два лічильники
- Сердечко зафарбовується золотим `#ffd700` при вподобайці; повторний клік знімає заливку і −1
- Захід на цю сторінку дає +1 перегляд, один раз на людину
- Головна і інші сторінки без лічильника перегляди не рахують

## 2. Як це зроблено

### Іконки

`assets/icons/discord.svg`, `telegram.svg`, `modrinth.svg`, `reddit.svg`.

`.side-slot` більше не сіре коло, лише картинка 36×36.

### Лічильники

- `js/stats.js` — клієнт
- `server.py` — маленький сервер на стандартному Python
- `data/stats.json` — цифри і списки хто вже дивився / лайкнув

Сторінка з лічильником має `data-page-id` (зараз `post`). Далі під кожним постом буде свій id.

Людина поки = id у `localStorage` (`dandelion-visitor`) і cookie. Це не акаунт: інший браузер або очищення даних = нова людина.

Якщо `server.py` запущений, цифри спільні для всіх, хто відкриває сайт через нього.

Якщо відкрити файл напряму — сервера немає, тоді лічильник живе тільки в цьому браузері (щоб механіку все одно було видно).

Запуск:

```
python server.py
```

Далі: http://127.0.0.1:8080/

### SQL

SQL зараз не стоїть і не потрібен. Файл JSON вистачає для кількох сторінок.

SQL варто буде додати пізніше, коли з’являться багато постів, коментарі й акаунти.
