# Етап 32. Збір етапів 01–30 в один файл

Дата: 19.08.2026

---

## 1. Що змінено

- Етапи 01–30 зібрані в `docs/STAGES_01-30.md`.
- Окремі `STAGE_01_…` … `STAGE_30_…` видалені.
- Правило на майбутнє: кожні 30 етапів знову збирати в один файл.

---

## 2. Як саме

У збірці є короткий зміст і повний текст кожного етапу як був.

`STAGE_31_SCROLLBAR_SMALLER.md` лишився — він уже з наступної тридцятки.

---

## 3. Що варто знати

Наступний збір — коли буде етап 60: файл `STAGES_31-60.md`.

---

## 4. Обмеження

Історичні етапи в збірці описують стан на той момент (наприклад демо-моди з етапу 01 потім прибрали).
