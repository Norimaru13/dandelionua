# Етап 65. Фіксована картка проєкту

Дата: 21.08.2026

---

## 1. Що змінено

- Прев’ю на картці проєкту завжди квадрат 160×160, не розтягується в прямокутник, коли опис чи фільтри довгі.
- Уся картка проєкту фіксованої висоти: назва один рядок, тіло 160px, низ 48px.
- Короткий опис — ліміт 300 символів (лічильник `0/300` у формі; зайве обрізається при вводі, вставці і збереженні). Якщо треба менше — змінити `LEAD_MAX`.
- Права колонка: 2/3 під опис, 1/3 під фільтри. Обидві комірки завжди на місці.
- На головній у фільтрах лише стан, версії і лоадер (Forge / Fabric / …). Тип і статус там не показую.
- Фільтри виглядають як кнопки (`#6371af` з обводкою), але це не кнопки — лише підписи.
- Знизу зліва лайки / дизлайки / перегляди / лічильник коментарів, справа «написати коментар» (або топ-коментар).

Пости не чіпав.

---

## 2. Як саме

CSS `.post-is-project`: сітка `160px 1fr`, `align-items: start`, прев’ю з `aspect-ratio: 1 / 1` і жорсткими 160px. Опис `flex: 2`, фільтри `flex: 1`, overflow hidden. Футер: спочатку статистика, потім коментар.

JS `js/posts.js`: чіпси `.proj-filter-chip`, `pageKind()` вирішує компактний набір на головній. `LEAD_MAX = 300`. Кеш `?v=67`.

---

## 3. Що варто знати

Ліміт опису легко зменшити: константа `LEAD_MAX` у `js/posts.js` і підпис `0/300` у формі.

На `projects.html` фільтри повні (тип, платформи, версії, стан, статус).

---

## 4. Обмеження

Якщо версій дуже багато, зайві чіпси ховаються — комірка фільтрів не росте.
