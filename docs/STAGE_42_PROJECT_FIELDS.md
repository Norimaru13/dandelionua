# Етап 42. Проєкти, дата справа, RGB

Дата: 20.08.2026

---

## 1. Що змінено

- Дата поста справа. Три крапки меню — текст `...`, щоб були квадратні в Tiny5.
- Для типу «проєкт» немає великого текстового поля і української назви. Назва завжди англійська. Лишається короткий опис.
- Замість тексту: тип проєкту (кілька), стан, статус, версії (кілька, як у таблиці), платформи Fabric / NeoForge / Forge.
- Окреме прев’ю: завжди квадрат, неквадратне обрізається від центру.
- RGB завжди на фіксованому місці (поле не стрибає). Повзунки вертикальні, сірі прямокутні бігунки з чорною обводкою, кольорові доріжки. Код кольору у форматі `#28402f`.

---

## 2. Як саме

Мета проєкту лежить у `posts.meta` (jsonb). Прев’ю — `preview_mime` / `preview_data`. SQL: `docs/post_project.sql`.

Публікації лишаються зі старим редактором тексту.
