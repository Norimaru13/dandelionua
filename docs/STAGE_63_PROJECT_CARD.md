# Етап 63. Картка проєкту, коментарі, дизлайки

Дата: 21.08.2026

---

## 1. Що змінено

- Над скрепкою прев’ю видно ім’я файлу, по верхньому краю квадрата.
- Картка проєкту за макетом: назва на всю ширину, підкреслена, веде на сторінку проєкту; зліва прев’ю; справа короткий опис і фільтри; знизу коментар / лайки, дизлайки, перегляди, лічильник коментарів.
- Модалка коментарів: список, B/I/U/S, 300 символів і лічильник `0/300`. Писати можна лише з профілем. Без модалки на картці — коментар з найбільшою кількістю лайків.
- Дизлайки там, де були лайки (пости і коментарі).
- Сторінка проєкту: `project.html?id=...`. GitHub Pages не може створювати окремий HTML на кожен проєкт, тому одна шаблонна сторінка. Дизайн як головна, без текстів і таблиці, лише назва.
